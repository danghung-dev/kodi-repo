# Family Cinema Kodi repository

Cài một lần: tải [repository.familycinema-1.0.0.zip](https://raw.githubusercontent.com/danghung-dev/kodi-repo/main/repository.familycinema/repository.familycinema-1.0.0.zip),
rồi trong Kodi: Add-ons → Install from zip file. Sau đó cài Family Cinema từ
Install from repository → Family Cinema Repository. Bật tự cập nhật add-on để nhận bản mới.

Trên tivi: Settings → File manager → Add source → `https://danghung-dev.github.io/kodi-repo/`,
rồi Add-ons → Install from zip file → chọn nguồn vừa thêm.
